# Codex 总管接入一期

已获用户 Confirm development 授权。复用本机 ChatGPT 登录，不使用 API Key。

- 独立总管通道，Ollama 继续基础整理，不覆盖原模型配置。
- 设置页检测登录、真实测试；部门主管和复核阶段可调用 Codex。
- 异步任务自动保存结果、失败原因，刷新可恢复查看。重复提交不重复执行。
- 只发送目标、背景和已有阶段文字；原件由用户人工脱敏后提供。
- 第一阶段不唤醒 WorkBuddy、豆包，不把名单当成真实执行。
- Codex 在隔离目录只读运行，不直接修改台账；后台验证结果后写入最新台账。
- 验收：真实连接成功、拆解自动保存且读回一致、失败不误完成、原有测试通过。

## 使用

设置 → Codex 项目总管 → 测试 Codex 连接。无需 API Key。

虚拟部门 → 建立工作链 → 部门主管 → 交给 Codex 总管拆解。
执行阶段已有成果并完成后，可在独立复核卡片调用 Codex（不能自审）。

调用采用已登录的订阅身份。使用隔离工作目录和只读模式；仅将提供的目标、背景、阶段文字送入模型，材料路径本身不会自动读取原件。服务端读回结果后写入最新台账。失败返回待启动，重试不删除历史记录。

Windows 没有进程级代理时，读取现有系统代理；只支持启用的 127.0.0.1:端口，不修改系统设置。不继承 API Key；忽略用户运行配置以免加载个人工具与通知。

后续：接通 WorkBuddy/豆包任务执行及真实文件交接、按事件自动唤起总管。本期仍需点击启动总管。
