# 统筹工作台 v0.5 · 每日行程多视图与闭环

## 目的

让同一份本机日程台账可以按日、周、月查看；重点工作在开始前 12 小时发送微信提醒；每条行程可直达已登记的材料；日程和复盘可形成由当前模型路由润色的报告草稿。

## 约束

- 日、周、月只查询 `agendas`，不得复制或另存第二套日程。
- 周视图为日期锚点所在自然周（周一至周日）；月视图为日期锚点所在自然月。
- 微信 Token 只保存于本机 `data/store.json`，迁移时不输出、不同步、不写入源码；旧 daily-plan 的浏览器数据仅读取 PushPlus／Server酱配置。
- 推送仅用于 `important=true`、有准确日期与时间、且未完成的事项；每项最多成功发送一次。
- 材料只保存路径文本。打开操作只接受该事项已登记且当前存在的本机文件或文件夹路径，不执行命令字符串。
- 报告仅以本周期的日程描述、完成状态、复盘和材料数量作事实底稿；模型不得增加事实。默认走本地 Ollama，用户切换在线模型时才发送至其已配置接口。

## 验收清单

- [ ] 右上角可切换日／周／月，日期导航正确改变锚点。
- [ ] 周、月按日期分组显示本周期所有已录入行程，点击日期可进入日视图。
- [ ] 新增行程可登记多条材料路径；已登记且存在的路径可由本机服务打开。
- [ ] 重点事项在开始前 12 小时经迁移的 PushPlus／Server酱通道成功发送，且不会重复发送。
- [ ] 日／周／月页底部可生成对应报告草稿；草稿只采用本周期日程与复盘，并可编辑后保存到报告库。
- [ ] 原行程新增、完成、复盘、删除、主题与 Ollama 功能仍可用。
