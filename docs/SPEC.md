# 本机统筹工作台 v0.2 规范

## 目的

给 BEN（董事长）一个私人秘书式指挥台：打开先看三份自动简报，然后进入 Slack 式三栏。把控全局、计划未来；新项目/新部门能在首页加模块，并能按重要性改顺序。工作区里可以直接给 Agent 下达。

## 读者

BEN 本人。其他 Agent 通过 inbox / checkpoint 对接，不另建台账。

## 不是什么

v0.1 的「任务看板 + 左侧单栏」不是目标形态。看板可以藏在事业部里，不能当首页。

## 开屏

每次打开（当日未关闭过）弹出 **三份简报**，一份一份看完或跳过今日：

1. 经营简报 — 今日行程、该写的报告、下一步三件
2. 舰队简报 — 各部门（Agent）在办、进度、待回指令
3. 三条战线 — 工作 / 学习 / 生活进度

简报由台账自动生成，标题可在设置里改。不假装已连上 Slack 官方接口。

## 主界面（对照 Slack）

- **最左一级导航栏**：使用完整名称展示（指挥舱 / 决策台 / 每日行程 / 简报中心 / 经营 / 舰队 / 事业部 / 学习 / 生活 / 记忆 / 设置），不使用单字缩写。
- **中栏**：二级目录（模块、报告种类、某个 Agent、某个事业部）
- **右栏工作区**：该对象的进度、报告正文、模块画布；底部可向当前 Agent 或事业部下达

## 模块化指挥舱

首页是可增删、可拖拽排序的模块。新事业部上线 = 新模块出现在指挥舱。顺序代表你此刻要盯的优先级。

## 经营秘书

行程、日报、每日复盘、周指导、周报、月评估、月报、季度总结。从台账生成初稿，人话由你改。

## 舰队

自动汇总各 Agent 最近打卡与事件。下达写入 inbox，对方用 `GET /api/inbox?agentId=` 领取。

## 约束

- 仍绑定 127.0.0.1，零 npm 依赖
- 红区信息不准写入
- Slack 外观是布局参考，不复制商标与插画

## 对照核验

- [ ] 打开后先出三份简报，关完进三栏
- [ ] 左栏一级、中栏二级、右栏工作区
- [ ] 指挥舱模块可新增、可拖拽改序，刷新后仍在
- [ ] 经营里能生成复盘 / 日周月季 / 周指导 / 月评估
- [ ] Agent 工作区能看进度并下达，inbox 可被 API 读取
- [ ] 工作 / 学习 / 生活都有战线模块
- [ ] 外观接近附截图：紫侧栏 + 白工作区 + 底栏指令框
