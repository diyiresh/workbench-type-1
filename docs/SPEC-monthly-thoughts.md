# 月度思考与反思记录

2026-11-01 用户 Confirm Development。新生成采用 thoughts-v1；既有简短月报、原行程报告及真实草稿保留，不自动重生成、保存或推送 GitHub。

- 从所选月的有效行程逐项取材：完整备注、原始复盘，以及对应 Obsidian 最新有效笔记的完整正文（包括摘要和原始复盘）。按日期/时间排序，不因未保存摘要而漏掉行程。
- 备注中的计划和创意仍是计划/创意；只有时间表、训练清单或事项描述时标注“未记录个人反思”，不能补造用户判断、情绪、动机或推理。已保存整理与原文不一致时保留来源和修正关系，无法确定的冲突明确列出。
- 采用独立写作规则，不再套用 450—650 字工作月报模板。逐项解释问题、判断、理由、约束、具体例子、反思/纠正、后续想法，再归纳跨日期的认识变化；按实质材料决定篇幅，不设置短篇总字数目标，不以泛泛结论代替推理。
- 输出缺项时不允许以完整记录落盘；用户人工补齐全部来源章节和月度思考脉络后，可基于未变化的原始来源正常保存。原始返回文字及未完整回执仍保留。
- 每项行程固定 A001 等来源编号，输出每项独立标题及对应段落；无个人反思的项也明确列出。末尾归纳月度思考脉络，引用来源编号。返回缺少行程章节或章节为空时保留完整输出为待核对草稿，提示缺失，不自动当作合格新稿替换。
- 预览显示行程总数、原始复盘数、完整笔记数及逐项来源。有数据但无 Obsidian 摘要时仍可生成；空月不派发。
- 以 reportProfile=thoughts-v1 隔离新旧底稿/哈希/规则；旧 saved-reviews 作业继续按旧规则核对，不因升级变成来源失效。新任务绑定完整文字及文件哈希，修改原始复盘或备注也使新任务旧结果失效。
- 沿用 Codex/Cursor/WorkBuddy、原预算及成员占用；SiliconFlow 保持暂停。生成材料来自固定月度输入，参考现有已核验的 Codex 完成/失败事件适配，无新增模型服务/依赖。保存仍需用户确认，导出保留完整正文、profile、逐项来源与文件哈希。

验收：完整备注/复盘/笔记传递、25条覆盖预览、缺摘要仍纳入、空月/异常文件、无简短字数限制、逐项覆盖检查与未完整输出保留、旧作业不变、新输入变更保护、三成员替身及版本导出、前端展示/编辑/恢复/保存回归。隔离测试不冒充真实长文质量验收。
