## 技术路线

保留 Node.js HTTP 服务和原生 ES Modules。lib/archive.js 集中维护允许集合、关联预览、归档/恢复/继续及执行资格。页面统一管理面板使用原始台账，常规页面使用过滤视图。翻译只作用于系统文案，动态业务数据不作 DOM 批量替换。i18next 与 Mermaid 通过本地打包加载。

执行顺序：数据规则与回归 → 页面管理 → 语言 → 使用说明/图形 → 自动与浏览器验收。
