# 项目自动恢复（2026-11-22 已确认范围）

用户已 Confirm Development。保留唯一台账及四阶段交付门禁，新增按项目配置的恢复策略。

- 新项目默认允许有限自动恢复；已有项目须明确开启，最多三次连续调用，跨执行成员和输入文字调整累计，不清除历史预算。
- 仅对受控只读 CLI、有本地关闭证据的暂态网络/返回格式故障自动恢复。身份错配、仍存活/未知会话、登录、权限、暂停及用户决策继续显式处理。
- 恢复计划持久化：来源尝试、输入哈希、控制代数、策略、原因、下次执行时间；恢复采用固定幂等键。暂停、改派、输入或策略改变使旧计划失效。
- 默认退避 30 秒、120 秒；同类错误第二次后改变策略。允许预先确认的 Cursor→Codex 独立复核替补，执行人与复核人不同。
- 已完成正文和 DOCX 不因复核通道故障重做。退回成果仍沿用内容返工轮次门禁。
- WorkBuddy 领取时返回指定正文草稿路径；提交脚本读取实际领取凭证并校验当前台账后原子封装结果，拒绝覆盖冲突成果和猜测历史凭证。
- 群聊记录恢复原因、计划动作和待人工处理事项；执行面板集中配置策略、批准正式写作、改派及原有审核/暂停操作。
- 重启后，只有确切匹配当前 attempt、仍为 queued、无领取和启动证据的 WorkBuddy 请求才能按原预算自动接续；补充证据后的旧待处理判断保存在 recoveryHistory。已领取或身份未知的执行仍须核对。

验收：只读 CLI 网络失败后单阶段恢复；相同错误两次后策略调整；暂停/输入变化取消旧计划；重启后保留计划与幂等归属；预算耗尽出现待处理提示；暂停/过期/错误身份不能提交；独立文件验收仍有效。
