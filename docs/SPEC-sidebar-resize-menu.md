# 二级侧栏调宽与项目菜单

2026-10-18。依据 PLAN-sidebar-resize-menu.md 获用户 Confirm Development 后实施。仅修改浏览器布局与菜单展示，不改变项目管理操作、业务台账或 Agent 调度。

## 交互与实现

- `public/js/sidebar-resize.js` 管理桌面宽度：最小 200px，最大为 420px 与“窗口扣除一级导航和 360px 主区”两者的较小值。未设置偏好时沿用 236px／208px（第三分支紧凑布局） 响应式默认值。
- 右边界为 8px 透明拖动区，悬停、键盘聚焦及拖动时显示 2px 主题高亮线。采用原生 Pointer Events 与指针捕获；鼠标和触控笔共用同一入口。
- 拖动结束才将宽度写入浏览器 `bench-secondary-sidebar-width-v1`；切页、刷新及收起后展开保留。窗口变小时只限制实际显示宽度，不覆盖较宽窗口的偏好。无效存储忽略，存储不可用时内存回退。
- 分隔条具有 separator 角色、vertical 方向、数值上下限与当前值、双语可访问名称。左右箭头每次 8px，Shift 为 32px；Home／End 到上下限。双击或 Enter 清除偏好，恢复当前窗口默认值。
- 取消指针、丢失捕获、Escape、窗口失焦、窗口缩放、页面隐藏及侧栏收起会结束拖动并恢复此前偏好，不遗留光标或禁止选中状态。720px 及以下仅使用原抽屉，不显示分隔条。
- 开关、调宽不替换表单节点；当前消息、搜索和草稿保留。布局高度限制在窗口内，二级列表自行滚动，避免长项目列表撑高整个工作区。
- `public/js/project-menu.js` 管理现有 details 菜单的浮层：原四个按钮留在原 DOM，原管理事件及确认流程不变。使用原生手动 popover 跳出滚动裁切，按可视区域选择上方／下方并限制边界；不支持 popover 时以 fixed 定位回退。
- 菜单背景、文字、边框及悬停使用配套主题变量，修复浅底继承浅字。单次只开一个菜单；点击或聚焦外部、滚动、缩放、相关内容隐藏／替换时关闭。Escape 先关菜单并回到触发点，窄屏再次 Escape 才关闭抽屉。

参考 [Split.js](https://github.com/nathancahill/split/blob/master/packages/splitjs/README.md) 的分隔条、宽度约束与保存思路；沿用原生 JS/CSS Grid，无新增依赖、接口或数据迁移。页面 Ctrl+F5 加载，无需重启。

## 验收清单

`test/sidebar-resize.browser.cjs` 使用临时台账、24 条额外长标题项目与真实浏览器：

1. 真实指针拖动、拖动结束前不持久化、结束后保存、切页／刷新保持；收起后恢复宽度。
2. 键盘步长、上下限、默认恢复；缩小窗口后保留 360px 主区，扩大后还原偏好。
3. 消息和搜索为同一 DOM 节点且原文不丢失；指针取消、丢失捕获、Escape、失焦及拖动中收起均清理状态。
4. 移动抽屉不显示分隔条；无本机存储与非法偏好仍能操作。
5. 长列表确实滚动，末尾菜单在可见区域；桌面与手机菜单能退出，Escape 焦点返回不误关抽屉。
6. 四主题、中英文，普通菜单和悬停文本对比度至少 4.5:1；原菜单按钮及业务集合一致，交互无业务写请求、无外部请求。

既有 compact-layout 浏览器回归及全套 UI 回归继续验证原纯图标开关、草稿、四行展开、业务管理与其他模块。真实 Agent 业务调用不属于此次验收。
