# V9 履职成长：使用与验收

版本：9.0.0-beta.1。新增履职学习与管理训练功能，沿用V8预览壳层和原版布局；不代表完成全部历史V8视觉改造。

当前运行边界：本机原3780服务的自动重启操作被执行策略拒绝（工具返回blocked by policy），未停止原进程。可用 `node scripts/v9-preview.cjs` 启动3790端口隔离演示；它使用系统临时目录内的独立演示台账，不启动后台工作器，并拒绝V9保存之外的业务写操作。演示记录不会自动迁入正式台账。正式服务需要在原Node服务正常退出后，从本项目重新启动，才能加载新接口。

## 开始使用

1. 打开“知识库 → 履职成长 V9”，或访问本机 `http://127.0.0.1:3780/#learn/growth`。原版布局从“学习成长 → 履职成长 V9”进入。
2. 在概览中选择第一周开始日期，点击“采纳八周计划”。保存40项学习安排，每周300分钟，跨日历年也按实际日期计算。再次采纳不会复制计划。打开页面本身不会采纳。
3. “八周路径”勾选学习活动。全部完成后分次记录仍保留，也能取消勾选。安排时长不等于实际投入时长或掌握证明。
4. “工具卡片”有重点事项、概念与文件、案例分析、管理复盘、每周一页纸五类模板。卡片可引用原有任务和行程，原进度不被复制或修改。
5. 概念和案例记录掌握程度。升至“能解释”或“能分析”需理解证据、出处名称及链接或页码；“经复核可复用”还需专业核对人、意见与本版核对确认。
6. 修改已复核内容、证据或出处时，旧复核留在历史，本版退回不高于“能分析”。需要重新专业核对才能恢复最高等级。复核记录由本人据实登记。
7. 每周路径可按当前记录生成“一页纸草稿”。未核实的现实成果和下周安排留待本人补充，审阅后保存；生成草稿本身不写台账。
8. “资料与指令”提供官方入口、发布时间与入口核验日期。点击“创建阅读卡”不会将个人阅读状态自动记为已读。教学指令可复制，不会自动调用模型。

## 草稿、版本与归档

- 编辑草稿保留在当前浏览器会话，支持切页和刷新。保存成功才清除相应草稿；关闭浏览器会话后不保证保留未保存内容。
- 保存和归档使用预期修订。另一窗口改过记录时拒绝覆盖，保留草稿；“重置为已保存内容”会在本人确认后重新获取最新版本并替换草稿。
- 卡片归档可恢复，未保存的编辑草稿继续保留。历史版本展示原文、掌握等级、核对人和意见。
- 保存回执丢失时，创建请求键用于避免重复卡片。若后续输入已变化，旧保存被确认后仍保留新改动为草稿，再次审阅保存。
- V9计划沿用现有学习计划集合；其归档与恢复使用原“管理与归档”机制。原有通用学习计划的完成逻辑保持不变。

## 数据和权限

全部业务记录仍在本机唯一台账。V9预设为公开业务主题和官方链接。V9功能不自动浏览资料、不调用Vault、不启停WorkBuddy、不发起Agent任务，不改变模型配置、外部工具和既有行程。

V9写接口仅允许本机同源请求。出处链接限制为不含凭据的HTTP/HTTPS地址，用户文本按普通文本显示。真实内部材料按既有授权和脱敏要求使用。
