## 2. 用户真正要解决的问题

1. 本机工作台统一管理事务、行程、简报和成果，减少在多个 Agent 间来回转发与手动回填。
2. 保留 WorkBuddy 的优势，默认正式协作为 Codex 主管／整合、WorkBuddy 执行、Cursor 独立复核；执行人不得自审。
3. 各模块职责清楚，同一任务不出现多份进度；统计数字与可点击筛选列表一致。
4. 将跨 Agent 的经验、纠错和教训变成用户确认、可追溯、可测试的技能，不只记录一句“下次不要再犯”。
5. 知识资料要有可视化来源及检索状态；独立行程复盘须与 VaultRAG 隔离，避免过时人物／事务观点污染全库。
6. 提升界面可读性：四字中文导航、主题／语言、可收起／调宽的二级栏、长内容按需展开。
