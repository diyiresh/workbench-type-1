## 已核对的接口边界

WorkBuddy 官方企微指南支持用户向机器人发送指令。企业微信官方 Node SDK 的 sendMessage 是机器人向会话发送 Markdown/卡片/媒体，并不是以用户身份向另一个机器人发指令。程序通知能否产生接收机器人的任务回调，必须真实测试。连接器/MCP 能被任务调用，不等于创建任务的唤醒接口。

## 测试条件

使用个人专用测试会话，不向业务群发布。不复用 WorkBuddy 已绑定机器人 Bot ID/Secret；第二个发送机器人拥有独立连接。Secret 只在本机环境变量 BEN_TEST_WECOM_SECRET 配置，不发到聊天、不放进台账。账号创建、登录与授权由用户完成。

scripts/wecom-trigger-probe.js 是隔离的单功能测试脚本。prepare 建立唯一编号及合成算术任务；send 使用官方 @wecom/aibot-node-sdk（需在测试环境安装），发送一次；verify 读取 WorkBuddy 写回的编号匹配结果。未配置条件不会发送。sending/notification_accepted/send_uncertain 均不能重发；后者表示需要核对，不能自动再试。原始凭据及服务器响应不写入日志。

在 data/wecom-probe/config.json 配置 senderBotId、receiverBotId、chatId、testOnly=true、senderSecretEnv=BEN_TEST_WECOM_SECRET；这些标识应由实际测试环境提供，不猜测，不使用业务群。当前尚未创建该配置。
