# 界面精简与展开交互

2026-10-18。用户审查 `PLAN-compact-layout.md` 后 Confirm Development。前端展示功能，保留唯一台账及全部原始业务内容。

## 交互规则

1. 一级中文名称为：工作首页、项目中心、成员中心、每日行程、简报中心、工作报告、资产中心、学习成长、生活管理、系统设置。按钮同宽同高、居中；英文按自然表达排版。路由 ID、旧链接及业务文本不更名。
2. 二级栏顶部只显示一个纯图标开关，收起后同一个按钮移到一级导航顶部，主工作区不放置开关或解释文字。保留 title、aria-label、aria-expanded 与键盘操作。宽屏隐藏二级栏后主工作区占用释放的宽度，保留一级导航；首次默认展开，本浏览器的选择存于 `bench-secondary-sidebar-v1`。存储不可用时使用内存，不写入台账。
3. 720px 及以下用独立抽屉状态，默认关闭。使用同一个图标关闭，或通过遮罩及 Escape；关闭后返回开关。打开时限制焦点在抽屉内，主区和一级导航暂设 inert；选择二级入口后关闭。窗口尺寸改变时恢复宽屏偏好，不将手机开关写成桌面偏好。
4. 开关只切换布局，不调用页面 render，不替换表单节点，因此保留当前消息、选择、行程等未提交输入。后续正常业务刷新继续沿用原草稿规则。
5. 四角色的 `instruction` 和退回意见 `review.comment` 各自默认四行预览。退回意见标题始终显示，实际渲染超过四行时在正文下显示“展开详情”，展开后显示完整原文，并可“收起详情”；短文、空文不显示开关。正文保留换行，长路径可换行，所有文本先转义。
6. 展开状态按项目、阶段及内容类型独立区分；展开说明不同时展开退回意见。同页正常刷新状态时保留，离开后或浏览器刷新后回到默认收起。浏览器窗口缩放后重新测量是否需要开关。状态、负责人、执行动作及原有阶段成果展开入口独立保留。

## 实现位置与边界

- `public/js/compact-layout.js`：浏览器偏好、侧栏及抽屉控制、阶段展开状态与溢出测量。
- `public/js/navigation.mjs`：中文一级导航名称；`public/app.js`、help 和 crew 观察卡同步系统文案。
- `public/js/views.js`：阶段说明及退回意见调用安全展示函数；完整原文仍从原台账读取。
- `public/index.html`：导航侧图标容器和遮罩；`public/styles.css`：宽度释放、窄屏、焦点及四行展示。

交互参考 shadcn/ui SidebarTrigger 与移动/桌面状态分离，仅借鉴设计；未引入组件库、React 或新依赖。没有后端接口、数据迁移、Agent 启停或执行策略改动，正常刷新即可加载。
