# 统筹工作台 v0.4 · 主题、每日行程与本地大脑

## 目的

让工作台不仅展示任务，还能承载一天真实的时间安排；AI 必须先通过本地 Ollama 连通检查，再给出可人工采用的建议。

## 约束

- 数据仍只写入 `data/store.json`；每日行程不另用浏览器 localStorage。
- 默认直连 `http://127.0.0.1:11434`；`3002` 仅是 Open WebUI 管理入口。
- AI 输出只显示为建议，不自动生成日程、修改任务或对外发送内容。
- 保留紫色指挥舱，并提供暖白总控台、深色专注主题。
- 不迁移原 daily-plan 的 Gist、PushPlus、文件服务或令牌。

## 验收清单

- [x] 设置页可切换并持久化三种主题。
- [x] 设置页能显示本地 Ollama 状态、版本与模型列表。
- [x] 本地模型可启用并返回一次短文本响应。
- [x] 每日行程支持日期、时间块、重点、完成、复盘和删除。
- [x] 每日行程与既有周计划同屏显示，但不复制为第二套台账。
- [x] AI 日程建议只读现有事实，生成后不自动写入。
- [x] 原有指挥舱、决策台、舰队、模型路由及底部指令台保持可用。
